# `interactive.js` (Interactive Lesson Player)

This script is the core Controller and View layer for the actual learning interface (the "Game Screen"). It manages the progression of a lesson, heart system, UI rendering, and answer checking.

## Global State: `interactiveState`
```javascript
let interactiveState = {
    questions: [], // The array of question objects (often generated by engine.js)
    currentIdx: 0, // Current question index
    hearts: 5,     // Lives remaining
    maxHearts: 5,
    correctAnswers: 0,
    level: null,
    section: null,
    subsection: null,
    isChecking: false, // Prevents double-clicking the check button
    selectedMatchPairs: []
};
```

## Core Functions

### `startInteractiveLesson(workspace, data)`
Initializes the lesson.
1. Attempts to load data from `data.dataSource` (usually a JSON file).
2. If `data.type === 'dynamic_practice'`, it passes the raw vocabulary to `DynamicExerciseEngine.generate()` to get the `interactiveState.questions` array.
3. Sets up the UI (progress bar, hearts, footer).
4. Calls `renderInteractiveQuestion()`.

### `renderInteractiveQuestion()`
Determines what type of question is next and calls the appropriate renderer.
- Handles success/fail states (if `hearts <= 0` or `currentIdx >= questions.length`).
- Supported question types: `word_order`, `fill_blanks`, `true_false`, `match_pairs`, `dictation`, `image_choice`, `chat_story`, `speak_verify`.

### `checkInteractiveAnswer()`
The central validation function triggered by the "Ellenőrzés" (Check) button.
1. Normalizes user input (lowercase, strip punctuation).
2. Compares against the expected answer based on the `qType`.
3. Calls the PHP backend (`api/tts.php`) to generate high-quality audio for the correct sentence to reinforce learning.
4. Calls `showInteractiveFeedback(isCorrect)`.

### `showInteractiveFeedback(isCorrect, correctAnswerStr)`
- Updates UI colors (green/red).
- Plays success/fail sounds.
- If incorrect, deducts a heart and pushes the question to the *end* of the `questions` array so the user must try it again later.

## Exercise Renderers
Specific functions that inject HTML into the `#game-content` container:
- `renderWordOrderQuestion(container, q)`
- `renderFillBlanksQuestion(container, q)`
- `renderTrueFalseQuestion(container, q)`
- `renderMatchPairsQuestion(container, q)` (Auto-checks without needing the Check button)
- `renderDictationQuestion(container, q)`
- `renderImageChoiceQuestion(container, q)`

## Audio & TTS
- Uses `globalThis.speechSynthesis` as a fallback, but primarily tries to use a custom PHP backend (`api/tts.php`) for Google Cloud TTS integration.
- Includes a basic `AudioSynth` implementation for success/fail/pop sound effects.
